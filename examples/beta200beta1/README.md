# Beta-Beispiele / Beta examples

## Deutsch

Zum Einstieg **08-Beta-Manuell-Chat.json** herunterladen und als vollständigen Kampf in einen Testchat importieren. Der [Beta-Test Schritt für Schritt](../../docs/BETA-TESTPLAN.de.md) führt durch Angriffe, Heilung, Reaktionen und die Modellanbindung.

| Datei | Inhalt | Importart |
| --- | --- | --- |
| [01-Arena-12-Figuren.json](01-Arena-12-Figuren.json) | Kleine Arena mit zwölf Figuren | Vollständiger Kampf |
| [02-Advanced-KI-40-Figuren.json](02-Advanced-KI-40-Figuren.json) | Großer Test mit 40 Figuren und Advanced AI | Vollständiger Kampf |
| [03-Suchgruppen-Dungeon-50x50.json](03-Suchgruppen-Dungeon-50x50.json) | Suchgruppen auf einer 50×50-Karte | Vollständiger Kampf |
| [04-Advanced-Figurenprofile.json](04-Advanced-Figurenprofile.json) | Übertragbare Figurenprofile | Figurenprofile, kein vollständiger Kampf |
| [05-Alpha-Regeln.json](05-Alpha-Regeln.json) | Gespeicherte Regelkonfiguration | Regeln, kein vollständiger Kampf |
| [06-Namensvetter-Reaktionen.json](06-Namensvetter-Reaktionen.json) | Gleichnamige Figuren und Reaktionen | Vollständiger Kampf |
| [07-Suche-Alte-Fundstellen.json](07-Suche-Alte-Fundstellen.json) | Suche und alte Beobachtungen | Vollständiger Kampf |
| [08-Beta-Manuell-Chat.json](08-Beta-Manuell-Chat.json) | Sechs Figuren für manuelles Spielen, Reaktionen und Chat | Vollständiger Kampf |

Auf GitHub die gewünschte Datei über **Raw / Download raw file** herunterladen. Die Beispiele stammen aus früheren Betas und bleiben für gezielte Tests verfügbar. Die [deutsche Anleitung](../../docs/README.de.md) beschreibt die aktuelle Erweiterung.

## English

Start with **08-Beta-Manuell-Chat.json**, downloaded through GitHub's **Raw / Download raw file** option, and import it as a complete combat in a test chat. It contains six actors for manual play, reactions and model narration.

Files 01–03 provide a 12-actor arena, a 40-actor Advanced AI battle and a 50×50 search-party dungeon. File 04 contains portable actor profiles; file 05 contains rules only. Files 06–07 exercise namesake reactions and old search clues. Import 04 as actor profiles and 05 as rules; the other numbered files are complete combats.
