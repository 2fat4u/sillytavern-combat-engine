# Kartenbeispiele / Map examples · 2.0.0-beta.2

## Deutsch

Diese JSON-Dateien als vollständige Kämpfe in einen Testchat importieren. Die Szenen befinden sich in der Vorbereitung und enthalten vier manuell gesteuerte Figuren. Damit kann die Zufallskarte sofort neu erzeugt werden.

- **01:** kompakter Dungeon mit 12×12 Feldern.
- **02–03:** Dungeons mit 30×30 Feldern, großen beziehungsweise gemischten Räumen.
- **04–07:** lichter Wald, Baumgruppen mit Lichtungen, dichter Wald und Wald mit Weg.

Unter **Board → Zufällige Karte** Dungeon oder Wald auswählen. Die Waldeinstellungen erscheinen nur beim Kartentyp Wald. Gespeichertes Gelände bleibt erhalten, bis eine neue Karte erzeugt wird. Derselbe Seed wiederholt das Layout mit denselben Einstellungen und platzierten Figuren in dieser Version.

[Deutsche Anleitung](../../docs/README.de.md) · [Beta-Test Schritt für Schritt](../../docs/BETA-TESTPLAN.de.md)

## English

Import these JSON files as complete combats in a test chat. They are in setup with four manual participants, so random map generation is available immediately.

- 01: compact 12×12 dungeon.
- 02–03: 30×30 dungeons with large or mixed rooms.
- 04–07: light woodland, clusters with clearings, dense forest and a forest trail.

Under **Board → Random map**, select Dungeon or Forest. Forest layout controls appear only for Forest. Existing saved terrain stays unchanged until you generate another map. Reusing a seed repeats a layout with the same settings and placed participants in this version.
