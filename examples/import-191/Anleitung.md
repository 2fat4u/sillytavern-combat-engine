# Import-Testpaket 1.9.1

1. 01-Figuren.json über Figuren importieren laden. Vier neue Figuren, volle HP, noch nicht platziert.
2. Unter Waffen/Fähigkeiten/Aktionsbudget/Ressourcen Importieren wählen. Datei auswählen, Vorschau prüfen, Zielfiguren anhaken, Ergänzen oder Ersetzen und Importieren.
3. 06-Heilmittelpaket.json beispielsweise auf Mira und Lyra übertragen. Wiederholtes Ergänzen soll gleiche Vorräte nicht auffüllen.
4. Figuren aus der Übersicht aufs Feld ziehen. Nahkämpfer neben Rusk; andere nach Bedarf platzieren. Kampf starten.
5. Rusk anklicken, eine verfügbare Aktion auswählen, dann im vorausgefüllten Aktionsbereich ausführen. Gesperrte Einträge zeigen Gründe. Figur als Ziel übernehmen kostet nichts.
6. Alternativ 00-Testkampf.json über den normalen Kampf-Import laden: Figuren bereits aufgestellt. Heilung testen, nachdem eine Figur HP verloren hat.
7. 07-Zustaende-optional.json über den Profiltransfer auf eine gewählte Figur anwenden. Das ist eine bewusst getrennte Zustandsänderung.
8. Oberfläche → Debug-Modus einschalten. Einen ungültigen Import versuchen oder offline DM-Vorschlag anfordern. Fehlerprotokoll exportieren. Nach Neuladen ist der Sitzungspuffer wieder leer.

Heilzauber in dieser Version: eigene Ladungen. Angriffszauber teilen Mana, jeder Einsatz kostet weiterhin 1 Einheit. Einstellbare Kosten/gemeinsames Heil-Mana folgen später. Exporte aus offenen Editoren verwenden gespeicherte Werte; Änderungen zunächst übernehmen. In anderen Sprachen bleiben die frei vergebenen Figuren-/Waffennamen unverändert.
