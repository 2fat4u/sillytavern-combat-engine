# Contributors and development credits / Mitwirkende und Entwicklung

Tavern Tactics is created and maintained by **[2fat4u](https://github.com/2fat4u)**, with substantial development work performed using **ChatGPT/Codex (OpenAI)**.

- **2fat4u:** project idea and direction, gameplay and feature decisions, manual playtesting, feedback and release decisions.
- **ChatGPT/Codex (OpenAI), AI development contributor:** substantial portions of code implementation, debugging, automated tests, technical analysis and documentation, developed iteratively from the project requirements and playtest feedback.

Development combines AI-generated implementation, automated checks and manual playtesting. These credits describe the tools used to develop the extension. Normal play and numerical combat resolution do not require a language model; optional in-game narration uses the model configured by the player.

Future releases should retain this development credit in the README, extension metadata and release packages.

AI-assisted commits should also include the message trailer `AI-assisted-by: ChatGPT/Codex (OpenAI)`. This records the development tool without claiming a separate GitHub account.
