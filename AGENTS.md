Preserve the bilingual development credits in README.md, docs/README.de.md, CREDITS.md, manifest.json and release archives.

Keep the actual Git author identity. Record the AI tool through the credits and trailer; do not invent an AI GitHub account or email address. These instructions record the project owner's requested attribution convention.
